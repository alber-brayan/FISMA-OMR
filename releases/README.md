# Entregas Android

El archivo local `Fisma-OMR-1.1.0.apk` corresponde a la app firmada, versión 1.1.0, paquete `pe.fisma.omr`. La web lo descarga desde `/download_android_apk` cuando está presente aquí.

El APK se incluye en el ZIP completo de entrega, pero `*.apk` está excluido del repositorio de código. Está disponible en la [publicación A5.6](https://github.com/alber-brayan/FISMA-OMR/releases/tag/v2.0-fisma-a5.6). `SHA256.txt` permite comprobar su integridad.

La clave privada de firma no se distribuye con los fuentes ni con el APK.
