# Demostración sin datos reales

`Ficha_Demostracion.jpg` y `Lote_Demostracion.zip` se generaron desde la geometría A5 de esta edición. Contienen el texto «ESTUDIANTE DE EJEMPLO» y ninguna información de alumnos reales.

Para reproducir el ejemplo del manual, configura **Nivel VI / Público** con esta clave de prueba:

```text
A B C D E A B C D E A B C D E
```

Con puntaje **+10 por buena, -1 por mala y 0 por blanco**, la ficha de ejemplo devuelve **12 buenas, 2 malas, 1 en blanco y 118 puntos**.

El ZIP contiene `Nivel VI/Publico/Ficha_Demostracion.jpg`. Usa el ejemplo en una instalación de prueba o respalda previamente las claves y el registro de tu evaluación. No es una clave oficial de ningún examen.
